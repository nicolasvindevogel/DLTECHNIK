DL TECHNIK PWA V3.4 — Brouillons + verrouillage + photos multiples

NOUVEAU FONCTIONNEMENT RAPPORT
------------------------------
- une intervention peut être complétée progressivement ;
- bouton ENREGISTRER : conserve le rapport en brouillon ;
- le technicien peut quitter puis revenir plus tard ;
- bouton ENVOYER RAPPORT : transmet définitivement à WAPILOT ;
- après envoi, le rapport reste consultable mais n'est plus modifiable côté technicien ;
- corrections après envoi = uniquement depuis WAPILOT.

PHOTOS
------
- nouveau mode caméra intégré dans la PWA ;
- le technicien ouvre l'appareil photo une seule fois ;
- il peut prendre plusieurs photos à la suite ;
- miniatures des photos déjà prises en bas ;
- bouton Terminer pour envoyer toutes les photos ensemble ;
- bouton Galerie conservé comme alternative ;
- sélection multiple depuis la galerie également supportée.
