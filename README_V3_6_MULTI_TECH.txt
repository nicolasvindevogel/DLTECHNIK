DL TECHNIK PWA V3.6 — Plusieurs techniciens
- une intervention peut être affectée à plusieurs techniciens
- chaque technicien affecté la voit dans sa PWA
- lors d'une création terrain, le créateur peut cocher les collègues présents
- le créateur est automatiquement affecté
- un seul technicien rédige le rapport commun
- si un collègue a déjà commencé le brouillon, les autres voient que le rapport est déjà en cours
- nécessite SQL 15 + Edge Function V3.6
