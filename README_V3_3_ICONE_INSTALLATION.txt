DL TECHNIK PWA V3.3 — Icône d'installation écran d'accueil

Modifications :
- icônes PWA régénérées à partir du logo DL TECHNIK
- ajout de apple-touch-icon.png pour iPhone/iPad
- ajout des favicons
- manifest et theme-color ajustés au vert WAPILOT

À remplacer dans GitHub :
- index.html
- manifest.webmanifest
- sw.js
- icons/
- apple-touch-icon.png
- favicon-32x32.png
- favicon-16x16.png

IMPORTANT :
Si l'application a déjà été installée sur le téléphone, il faut souvent :
1. supprimer l'ancienne icône de l'écran d'accueil ;
2. recharger la page ;
3. la réinstaller.
Sinon le téléphone peut garder l'ancienne icône en cache.
